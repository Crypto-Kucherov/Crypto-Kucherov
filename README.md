## Current project

**[GitHub Activity Report](https://github.com/Crypto-Kucherov/crypto-dapp)** turns public GitHub data into Markdown, JSON and standalone HTML reports.

- Collect public repository and contribution evidence with explicit coverage limits.
- Compare saved snapshots and render reports offline.
- Keep missing or incomplete data visible instead of treating it as zero.
- Run with Node.js 22 or newer, with no runtime dependencies.
